Growth Spurt

This puzzle game was originally created for the Malmö Jams Too game jam, but was later expanded to a full mobile release. I did game design and level design.

Deduction-Game

A daily puzzle where 9 (good or evil) characters make statements about each other's team alignment and you have to calculate who is on which team. Only the good players can be trusted. Inspired by social deduction games.

Play Deduction-Game

Smash-Like

This is a platform fighting game (like Super Smash brothers) but designed to allow for crazy combos. (Homemade art)

Dance Mage

This is a turn-based roguelike spell-builder about dancing. (Beta art)

Move in specific sequences to cast powerful spells!

Made in the Godot game engine.

House Review

This is a relaxing stressful game about building houses using random blocks. When you decide to sell it your house gets critiqued according to 3 different metrics: walls, roof, and design (how well the pieces connect to each other). When you sell it you are paid accordingly. This is a unique game loop as far as I know. (Beta art)

Puzzle Game
